# a/mysteries data

The data behind posts on [a/mysteries](https://abstracts.co/a/mysteries), served by GitHub Pages at `https://abstracts-co.github.io/mysteries-data/<post>/`. A post on Abstracts holds at most 10 MB, so it carries a small page and loads its textures, terrain, data and narration from here. Each folder also works on its own as the full-window version.

| Post | Full window | Source |
| --- | --- | --- |
| Air crashes and disappearances | [air-crashes](https://abstracts-co.github.io/mysteries-data/air-crashes/) | [abstracts-co/mysteries](https://github.com/abstracts-co/mysteries), `source/air-crashes/` |

Sources and credits for every crash are listed inside the page. Earth imagery: NASA Blue Marble and VIIRS Black Marble through NASA GIBS. Elevation: Terrain Tiles. Local imagery: Sentinel-2 cloudless 2016 by EOX (contains modified Copernicus Sentinel data 2016). Stars: Yale Bright Star Catalog.
